# arXiv Preprint
“YOLOBirDrone: Dataset for Bird vs Drone Detection and Classification and a YOLO-based Enhanced Learning Architecture”

This work introduces a novel dataset and enhanced YOLO-based learning framework for bird vs drone detection and classification, addressing real-world challenges such as visual similarity and dynamic environments.

📌 arXiv: 2601.08319v1 [cs.CV], 13 Jan 2026
🔗 https://arxiv.org/abs/2601.08319
